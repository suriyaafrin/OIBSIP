# WebDev Level 1 — Task 1: Landing Page

## 📌 Project Description
A responsive, single-page landing page built as part of the OIBSIP (Oasis Infobyte) Web Development Internship — Level 1, Task 1. The page showcases a fictional product called **Horizon**, a goal-planning tool, with a clean hero section, feature highlights, an about section, and a footer with social links.

## ✨ Features
- Sticky/fixed navigation bar with 4 links (Home, Features, About, Contact)
- Hero section with headline, subheadline, and a call-to-action button
- Features section with 3 highlighted cards
- About section with contrasting dark background
- Footer with copyright and social links
- Fully responsive layout (mobile, tablet, desktop)
- Consistent color palette (green primary, amber accent, dark/light neutrals)
- Hover effects and smooth transitions on interactive elements

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- Google Fonts (Space Grotesk, Inter)
